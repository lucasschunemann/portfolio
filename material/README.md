# Material bruto

Jogue aqui o que for entrar nos cases, uma pasta por obra com o mesmo nome do slug:

```
material/
  acompanha/   prints das telas, exports do Figma
  acronos/     ...
  pf-advogados/
  wf-odontologia/
  traveldone/
  sendeski/    (já tem as duas telas originais do protótipo)
  von/         vídeos e prints da galeria
```

- Prefira PNG ou o export original, o maior possível (o site reduz e converte para WebP).
- Se puder, nomeie com o que mostra: `03-motor-de-creditos.png`.
- Algumas pastas já têm uma `notas.md` com perguntas: responda embaixo delas.
- Junto de cada pasta, um `notas.md` com: objetivo do cliente, problema, o que mudou, resultados com número real e o que você faria diferente. Pode ser em tópicos soltos.
- Esta pasta **não vai para o git** (só este README). O que for publicado fica em `src/assets/work/`.
